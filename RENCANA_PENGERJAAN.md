# Rencana Pengerjaan UTS — SIMPEL

## 1. Latar belakang masalah
Informasi akademik mahasiswa dapat tersebar di beberapa kanal, sehingga mahasiswa perlu berpindah tempat untuk memeriksa jadwal, mengingat tugas, atau mencari layanan. SIMPEL dibuat sebagai prototipe satu halaman untuk memperlihatkan bagaimana informasi dasar dapat ditata dalam satu antarmuka.

## 2. Tujuan
1. Membuat prototipe website informatif dan responsif.
2. Menerapkan HTML untuk struktur, CSS untuk tampilan, dan JavaScript untuk interaksi.
3. Mempraktikkan repository, commit, kolaborasi, serta publikasi melalui GitHub Pages.
4. Mengevaluasi fungsi prototipe melalui pengujian sederhana.

## 3. Sasaran pengguna
Mahasiswa yang membutuhkan tampilan ringkas untuk contoh jadwal, daftar tugas, dan alur pertanyaan akademik.

## 4. Fitur
- Beranda dan penjelasan proyek.
- Jadwal kuliah contoh.
- Daftar tugas dengan indikator progres otomatis.
- Formulir simulasi pertanyaan akademik.
- Navigasi responsif untuk perangkat mobile.

## 5. Pembagian kerja untuk 3 anggota
- Anggota 1 — Koordinator GitHub: membuat repository, mengatur struktur file, mengelola commit, mengundang anggota dan dosen.
- Anggota 2 — Pengembangan antarmuka: memahami dan menyesuaikan HTML/CSS, memeriksa responsivitas di laptop dan ponsel.
- Anggota 3 — Interaksi dan dokumentasi: menguji JavaScript/formulir, menyusun catatan eksperimen, mengedit video YouTube.
- Semua anggota wajib memahami tujuan, struktur file, cara kerja fitur, dan keterbatasan proyek. Tukar peran saat sesi review agar setiap anggota dapat menjelaskan proyek.

## 6. Rencana eksperimen dan bukti
| Eksperimen | Langkah | Bukti yang direkam | Hasil yang diharapkan |
|---|---|---|---|
| Repository | Buat repository publik atau sesuai instruksi kelas | Tampilan repository | Repository berhasil dibuat |
| Commit | Ubah satu bagian teks atau warna dan commit | Riwayat commit | Perubahan tercatat |
| Fitur tugas | Centang dan lepaskan centang | Layar progres | Angka dan bar progres berubah |
| Formulir | Kirim topik dan pesan | Pesan konfirmasi | Validasi dan konfirmasi muncul |
| Responsif | Buka website di lebar layar berbeda | Tampilan desktop dan mobile | Layout menyesuaikan |
| GitHub Pages | Aktifkan publikasi | Pengaturan dan URL website | Website dapat dibuka secara publik |

## 7. Pengujian
- Checkbox tugas mengubah angka selesai dan persentase.
- Formulir menolak input kosong dan menampilkan konfirmasi untuk input valid.
- Menu navigasi mobile dapat dibuka dan ditutup.
- Halaman dapat dibuka tanpa error tampilan utama.
- URL GitHub Pages dapat diakses setelah proses deployment selesai.

## 8. Kesimpulan sementara
SIMPEL menunjukkan bahwa website sederhana dapat membantu mengorganisasi contoh informasi akademik dan sekaligus menjadi sarana belajar pengembangan web. Prototipe ini belum menjadi sistem layanan kampus sungguhan karena belum memiliki database, autentikasi, atau pengiriman formulir ke server. Kesimpulan akhir ditulis setelah semua pengujian benar-benar dilakukan.

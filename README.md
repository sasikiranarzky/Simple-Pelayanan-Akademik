# SIMPEL — Sistem Informasi Pelayanan Akademik

SIMPEL adalah prototipe website untuk proyek UTS Sistem Informasi. Website ini merupakan demonstrasi pembelajaran, bukan layanan resmi kampus.

## Tujuan
- Menampilkan contoh jadwal akademik.
- Memperagakan daftar tugas interaktif.
- Menyimulasikan formulir pertanyaan/layanan akademik.
- Mempelajari repository, commit, kolaborasi GitHub, dan publikasi GitHub Pages.

## File
- `index.html` — struktur dan isi website.
- `style.css` — desain, layout responsif, dan tampilan mobile.
- `script.js` — interaksi daftar tugas, indikator progres, navigasi mobile, dan simulasi formulir.

## Menjalankan di komputer
1. Unduh atau clone repository.
2. Buka `index.html` dengan browser.
3. Centang beberapa tugas untuk melihat progres berubah.
4. Isi formulir layanan dan tekan tombol untuk melihat konfirmasi simulasi.

Tidak diperlukan instalasi paket atau server untuk prototipe ini.

## Publikasi melalui GitHub Pages
1. Buat repository baru bernama `simpel-pelayanan-akademik`.
2. Unggah ketiga file utama (`index.html`, `style.css`, `script.js`) dan `README.md`.
3. Buka **Settings → Pages**.
4. Pada bagian build/deployment, pilih deploy dari branch jika opsi tersebut tersedia.
5. Pilih branch `main` dan folder `/(root)`, lalu simpan.
6. Tunggu proses selesai dan buka URL yang ditampilkan oleh GitHub Pages.

Label dan menu GitHub dapat berubah. Pastikan `index.html` berada di root repository.

## Eksperimen yang disarankan untuk direkam
1. Buat repository dan jelaskan nama serta tujuan proyek.
2. Tambahkan file awal dan lakukan commit pertama.
3. Ubah teks atau warna kecil di `style.css`, lalu commit perubahan kedua.
4. Centang/lepaskan centang tugas dan tunjukkan progres berubah.
5. Kirim formulir simulasi dan jelaskan bahwa data tidak dikirim ke server.
6. Aktifkan GitHub Pages dan tunjukkan website yang sudah dipublikasikan.
7. Jelaskan satu kendala yang ditemui dan cara mengatasinya.

## Batasan prototipe
- Data jadwal dan tugas adalah contoh, bukan data akademik asli.
- Formulir tidak terhubung ke database atau server.
- Jangan masukkan data pribadi/sensitif ke website demo.
- Fitur login, penyimpanan permanen, dan notifikasi belum tersedia.
